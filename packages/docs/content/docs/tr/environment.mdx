# Environment Değişkenleri

ShipChamber bu environment değişkenlerini başlangıçta okur. Başlangıç servisleri için `shipchamber startup enable` varsayılan olarak mevcut environment'ı anlık görüntü olarak kaydeder. Servisin kullanmasını istediğiniz değişkenleri değiştirdikten sonra bunu yeniden çalıştırın.

## ShipChamber sunucusu

### `SHIPCHAMBER_HOST`

ShipChamber web sunucusu için bind adresi. Diğer makinelerden erişime izin vermek için `0.0.0.0` kullanın.

### `SHIPCHAMBER_UI_PASSWORD`

Tarayıcı arayüzü için parola. Bunu localhost dışına bind ederken, tünel kullanırken ya da reverse proxy arkasında çalıştırırken kullanın.

### `SHIPCHAMBER_API_ONLY`

`true` ya da `1` olarak ayarlandığında ShipChamber'ı headless modda başlatır. API rotaları masaüstü ve mobil istemciler için açık kalır, ama tarayıcı arayüzü sunulmaz.

### `SHIPCHAMBER_DATA_DIR`

ShipChamber veri dizinini geçersiz kılar. Varsayılan `~/.config/shipchamber`.

### `SHIPCHAMBER_CHATS_DIR`

ShipChamber'ın projesiz sohbetler için oluşturduğu yönetilen sohbet dizinlerinin yerini değiştirir. Varsayılan `~/.config/shipchamber/chats`. ShipChamber ve OpenCode farklı kullanıcılarla çalışıyorsa OpenCode sunucusunun okuyabileceği bir dizin belirtin. Mevcut sohbetler taşınmaz.

### `SHIPCHAMBER_COMPRESS_API`

API yanıt sıkıştırmasını kontrol eder. `true` ya da `1` ile zorla açın, `false` ya da `0` ile zorla kapatın.

### `SHIPCHAMBER_SKIP_API_COMPRESSION`

`true` ya da `1` olarak ayarlandığında API yanıt sıkıştırmasını kapatır. Bu ayar `SHIPCHAMBER_COMPRESS_API`'ye göre önceliklidir.

### `SHIPCHAMBER_VERBOSE_REQUEST_LOGS`

`true` ya da `1` olarak ayarlandığında ayrıntılı HTTP istek günlüklerini açar.

### `SHIPCHAMBER_UPDATE_API_URL`

Güncelleme kontrolü API uç noktasını geçersiz kılar. Çoğu kullanıcı bunu boş bırakmalıdır.

### `SHIPCHAMBER_PACKAGE_MANAGER`

Otomatik algılama yanlışsa, güncelleme işlemlerinin kullandığı package manager'ı zorlar.

## OpenCode sunucusu

### `OPENCODE_HOST`

ShipChamber'ı mevcut bir OpenCode sunucusuna bağlar. Değer, açık bir port içeren ve path, query ya da hash içermeyen bir `http` ya da `https` origin'i olmalıdır. `OPENCODE_HOST`, `OPENCODE_PORT`'a göre önceliklidir.

### `OPENCODE_PORT`

OpenCode sunucu portunu ayarlar. Yönetilen OpenCode ile bu, yönetilen portu ister. `OPENCODE_SKIP_START=true` ile harici bir sunucuya o port üzerinden bağlanır.

### `OPENCODE_SKIP_START`

`true` olarak ayarlandığında ShipChamber'ın kendi OpenCode sunucusunu başlatmasını engeller.

### `SHIPCHAMBER_OPENCODE_HOSTNAME`

ShipChamber'ın yönettiği OpenCode sunucusu için bind hostname'i. Varsayılan `127.0.0.1`.

### `OPENCODE_BINARY`

ShipChamber'ın çalıştırması gereken `opencode` yürütülebilir dosyasının yolu.

### `OPENCODE_CONFIG`

Belirli bir OpenCode yapılandırma dosyasının yolu.

### `OPENCODE_CONFIG_DIR`

Agent'lar, skills, snippets ve config keşfi için belirli bir OpenCode yapılandırma dizininin yolu.

### `OPENCODE_DATA_DIR`

Yönetilen OpenCode sunucusu için özel veri dizini.

### `OPENCODE_WSL_DISTRO`

Windows'ta OpenCode entegrasyonu için kullanılan WSL dağıtımını seçer.

### `SHIPCHAMBER_OPENCODE_WSL_DISTRO`

WSL dağıtımını seçmek için ShipChamber'a özel takma ad. İkisi de ayarlıysa `OPENCODE_WSL_DISTRO` önceliklidir.

### `OPENCODE_JWT_SECRET`

UI kimlik doğrulama token'larını imzalamak için kullanılan gizli değer. Kalıcı servis dağıtımlarında uzun ve rastgele bir değer kullanın.

## Terminal ve Git

### `SHIPCHAMBER_TERMINAL_SHELL`

ShipChamber terminal oturumları için kullanılan shell yürütülebilir dosyası.

### `SHIPCHAMBER_GIT_BINARY`

ShipChamber Git özelliklerinin kullandığı Git yürütülebilir dosyası.

### `GIT_BINARY`

Alternatif Git yürütülebilir dosyası geçersiz kılma değeri. ShipChamber'a özel yapılandırma için `SHIPCHAMBER_GIT_BINARY` tercih edin.

### `SHIPCHAMBER_GIT_READ_CACHE_TTL_MS`

Git destekli dosya okumaları için önbelleğin milisaniye cinsinden yaşam süresi. Hata ayıklarken bu önbelleği kapatmak için `0` verin.

## Voice ve tunnels

### `OPENAI_API_KEY`

OpenAI uyumlu servisleri çağıran ShipChamber voice özellikleri tarafından kullanılan API anahtarı.

### `SHIPCHAMBER_ALLOW_REMOTE_OPENAI_COMPAT_URLS`

`true` ya da `1` olarak ayarlandığında voice özellikleri için uzak OpenAI uyumlu base URL'lere izin verir.

### `NGROK_AUTHTOKEN`

ShipChamber tunnel komutlarının kullandığı ngrok auth token. `ngrok config add-authtoken <token>` ile de yapılandırabilirsiniz.

## Runtime yardımcıları

### `BUN_BINARY`

Daemon süreçleri başlatılırken ShipChamber'ın kullanması gereken Bun yürütülebilir dosyası.

### `BUN_INSTALL`

Bun kurulum kökü. ShipChamber bunu daemon başlangıcı ve güncellemeleri için `bin/bun` bulmakta kullanır.

### `VITE_OPENCODE_URL`

Vite ile derlenen web uygulaması için derleme zamanı API base URL'i. Çoğu kullanıcı bunu normal CLI ya da masaüstü kullanımında ayarlamamalıdır.
