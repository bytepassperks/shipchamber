Use Desktop if you want the full desktop app. Use Browser + PWA if you want to run ShipChamber through the web package. Use an editor extension if you want it inside your editor.
The builds are not code-signed yet, so each system is a little suspicious of them the first time. Windows: if SmartScreen shows a blue box, pick More info, then Run anyway. If a shortcut later says ShipChamber.exe is missing, Windows Security quarantined it: open Windows Security, Protection history, restore the file and choose Allow on device, then run the installer again. macOS: if it says the app is damaged or from an unidentified developer, run xattr -cr /Applications/ShipChamber.app in Terminal once, or right-click the app and choose Open. Linux: make the AppImage executable (chmod +x ShipChamber-*.AppImage); if it complains about FUSE, install libfuse2 or start it with APPIMAGE_EXTRACT_AND_RUN=1.
